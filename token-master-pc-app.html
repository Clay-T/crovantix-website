桌面整合流程送出前精簡
1. 偵測支援的 AI tool 輸入框支援 ChatGPT、Gemini、Claude、Perplexity、Copilot。
2. 顯示「精簡」按鈕使用者在對話框輸入 request 後，可先按精簡。
3. 替換為精簡後內容保留語意、限制與輸出格式，再由使用者確認送出。
桌面安裝方式Windows / macOS

正式版拆成兩種版本，兩者皆支援 macOS 與 Windows；瀏覽器支援 Chrome 與 IE。Chrome 使用瀏覽器外掛，IE 使用 Windows 桌面常駐 Helper / IE 整合模組。

一般使用者版

桌面 App + Chrome Extension + IE Helper，本機精簡 prompt，不需要 API Key。適合個人使用 ChatGPT、Gemini、Claude、Perplexity、Copilot 時按「精簡」後再送出。
